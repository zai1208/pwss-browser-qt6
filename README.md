# pwss-browser-qt6
## Description
This is a browser for PWSS (see https://github.com/zai1208/pwss) using Qt6 as a frontend

## Installation instruction

### Arch Linux
```bash
yay -S pwss-browser-qt6-git
```
An import of my PGP key is also needed `gpg --recv-keys 1D621CE3F6D554DC3E6E2551B1437E7DFC87A9B4`
